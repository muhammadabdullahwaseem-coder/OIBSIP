# OIBSIP Web Development Task 1: WebDev-L2-TributePage

A visually engaging, fully responsive tribute web page dedicated to **Nikola Tesla** ("The Genius Who Lit the World with Alternating Current"). Built as part of the Oasis Infobyte Internship Program (OIBSIP) Web Development Level 2 Track.

---

## 🌟 Key Technical Features

- **Hero Banner & Custom Portrait**: Includes a prominent hero image featuring Nikola Tesla alongside glowing electrical coils.
- **3-Paragraph Biography**: Detailed biographical content covering Early Life & Education, The War of Currents, and Tesla's Enduring Global Legacy.
- **Key Achievements Timeline**: Formatted as styled 6-card grid items covering AC Motor, Tesla Coil, Chicago World's Fair, Niagara Hydroelectric Plant, Teleautomaton, and Wardenclyffe Tower.
- **Blockquote Section**: Highlights Tesla's famous quote on energy, frequency, and vibration with custom typography styling.
- **Multi-Tone Background Palette**: Uses 4 distinct section background colors to partition content cleanly:
  - Hero Section: Dark Electric Gradient (`#0a0d17`)
  - Biography Section: Charcoal Slate (`#111827`)
  - Achievements Section: Deep Electric Indigo (`#1e1b4b`)
  - Quotes Section: Oceanic Dark Cyan (`#071524`)
- **Dual Typography Stack**:
  - Headings: `Playfair Display` (Serif)
  - Body Text: `Inter` (Sans-Serif)
- **Responsive Layout**: Designed for seamless viewing across smartphones, tablets, and desktop displays.
